# This repository is archived

WPML ElasticPress is no longer developed or released from this repository, and it no longer accepts changes.

- **Users of the plugin:** to report a problem or ask a question, contact [WPML support](https://wpml.org/forums/). Download WPML ElasticPress from your [WPML account](https://app.wpml.org/account/downloads). The releases up to 5.0.0 stay on this repository's Releases page, but newer versions are not published here.
- **WPML team:** the plugin now lives at [git.onthegosystems.com/wpml/wpml-core → `wpml-elasticpress/`](https://git.onthegosystems.com/wpml/wpml-core/-/tree/develop/wpml-elasticpress), with its full history and tags. Open a merge request there. It is still a separate plugin with its own version and zip, released from a `wpml-elasticpress/<version>` tag.

The history up to the move stays here for reference.
